# Implementation Plan: OpenRouter API Service Wrapper

**Branch**: `feat/openrouter-api-wrapper` | **Date**: 2026-07-23 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-openrouter-api-wrapper/spec.md`

## Summary

Create a self-contained OpenRouter integration layer at `src/integrations/openrouter/` that mirrors the Claude integration's architecture. The integration calls OpenRouter's OpenAI-compatible REST API via native `fetch` (no SDK), validates input with Zod, maps HTTP errors to the same five `SummarizationErrorCategory` values, and returns the shared `SummarizationResponse` discriminated union. This gives developers a free AI model for iterating on the summarization feature without consuming paid Claude API credits.

## Technical Context

**Language/Version**: TypeScript 5, Next.js 16 (App Router), React 19

**Primary Dependencies**: Native `fetch` (no new npm packages), Zod (already installed), `@t3-oss/env-nextjs` (already installed)

**Constraints**: Zero new npm dependencies. Must not touch the Claude integration. Must reuse existing types from `src/types/claude.types.ts`.

**Scale/Scope**: Development-only provider. 2 new files + env.mjs updates.
